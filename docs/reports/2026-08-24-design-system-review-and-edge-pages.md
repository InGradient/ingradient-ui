## 1. 목적과 범위

오늘 작업은 화면을 구성하는 공통 기준을 더 쉽게 이해하고, 실제 화면에서 같은 기준이 일관되게 보이도록 정리하는 데 초점을 두었다.

다음은 범위에 포함했다.

1. 로그인과 라이선스 화면이 공통 디자인 기준을 적용한 뒤에도 정상적으로 보이고 동작하는지 확인
2. 데이터 선택, 연결 설정, 촬영 설정 화면의 반복적인 배치와 글자 표현 정리
3. 색상·글자·간격·화면 크기 기준을 안내하는 토큰 화면 재구성
4. 화면을 만드는 기본 요소의 안내 화면을 더 보기 쉬운 구조로 정리
5. 키보드 사용자도 스크롤 영역을 사용할 수 있도록 접근성 보완
6. 오늘 완료한 작업을 기본 작업 공간에 반영하고 최신 미리보기 화면으로 갱신

다음은 범위에서 제외했다.

- 새로운 제품 기능 추가
- 기존 화면의 고유한 촬영 버튼, 이미지 표시, 슬라이더 같은 기능별 디자인 변경
- 오래된 백업 또는 시험용 원격 작업을 확인 없이 기본 작업 공간에 합치는 일

## 3. 로그인과 라이선스 화면 확인

### 3.1 확인한 화면 상태

로그인과 라이선스 화면은 공통 디자인 요소를 사용하도록 정리한 뒤에도 기존 사용 경험이 유지되는지 확인했다.

확인한 상태는 다음과 같다.

| 화면 | 확인한 내용 | 결과 |
|---|---|---|
| 일반 로그인 | 입력칸, 선택 항목, 버튼, 제목 | 정상 |
| 오프라인 로그인 | 오프라인 안내와 추가 버튼 | 정상 |
| 이전 계정 이어가기 | 인사말, 계정 목록, 계속하기 버튼 | 정상 |
| 로그인 실패 안내 | 입력된 값과 경고 문구 | 정상 |
| 라이선스 키 입력 전 | 장비 정보, 입력칸, 비활성 버튼 | 정상 |
| 장비 연결 필요 상태 | 안내 문구와 연결 버튼 | 정상 |
| 잘못된 라이선스 키 | 입력값, 활성 버튼, 오류 안내 | 정상 |

### 3.2 확인 결과

- 입력하지 않은 상태에서는 필요한 버튼이 비활성화되고, 값을 입력하면 사용할 수 있게 바뀌었다.
- 로그인 정보나 라이선스 키가 맞지 않을 때의 안내 문구가 정상적으로 표시되었다.
- 넓은 화면에서 내용이 옆으로 밀려 잘리는 문제가 없었다.
- 공통 기준을 적용한 뒤에도 화면별 기능과 상태 표현이 유지되었다.

## 4. 데이터 선택·연결·촬영 화면 정리

### 4.1 데이터 선택 화면

최근 사용한 데이터, 프로젝트별 데이터 묶음, 데이터 카드, 상단 제목과 설정 영역을 같은 기준으로 정리했다.

| 대상 | 정리 내용 |
|---|---|
| 최근 데이터 카드 | 제목, 프로젝트 이름, 이미지 수, 분류 정보의 배치 통일 |
| 프로젝트별 목록 | 제목, 역할 표시, 새 데이터 추가 영역의 정렬 통일 |
| 데이터 카드 | 제목과 정보 영역의 간격 및 정렬 통일 |
| 상단 영역 | 제목, 연결 상태, 새로고침, 설정 영역의 흐름 정리 |

### 4.2 연결 설정 화면

연결 설정의 여러 구역이 같은 세로 간격과 구분 방식을 사용하도록 정리했다.

| 대상 | 정리 내용 |
|---|---|
| 장치 검색 | 검색 버튼과 안내 문구의 배치 통일 |
| 연결·진단·네트워크 제어 | 구역 간 간격과 제목 흐름 통일 |
| 장치 목록 | 작은 화면에서 항목이 옆으로 밀리지 않도록 흐름 확인 |
| 저장된 설정 | 버튼과 상태 정보의 배치 통일 |

### 4.3 촬영 설정 화면

촬영 기능에만 필요한 고유한 모습은 유지하고, 여러 곳에서 반복되는 제목·행·안내 글·버튼 묶음만 공통 기준으로 정리했다.

| 대상 | 유지하거나 정리한 내용 |
|---|---|
| 촬영 버튼과 이미지 위 표시 | 촬영 기능의 고유한 모습 유지 |
| 촬영 대기와 연결 중 상태 | 안내 글과 정렬 방식 통일 |
| 측정값과 조정 항목 | 제목, 값, 구분선, 버튼 묶음 정리 |
| 설정 패널 | 제목, 저장·초기화, 선택 항목의 배치 정리 |
| 촬영 결과 검토 | 버튼 영역의 정렬 통일 |

## 5. 토큰 안내 화면 재구성

### 5.1 기존 문제

기존에는 비슷한 토큰 안내 화면이 두 곳에 있었고, 어느 화면을 기준으로 봐야 하는지 분명하지 않았다. 또한 밝은 화면과 어두운 화면을 바꾸어도 일부 값은 실제 적용 결과가 아니라 고정된 값으로 보였다.

전체 목록도 한 화면에 너무 많이 섞여 있어, 중요한 판단을 하기 어려웠다.

### 5.2 정리한 방향

대표 안내 화면을 하나로 정하고, 처음 보는 사람도 핵심을 먼저 이해할 수 있도록 구성했다.

| 구분 | 새 방식 |
|---|---|
| 대표 안내 화면 | 한 곳을 기준 화면으로 지정 |
| 예전 수동 목록 | 값 확인용이 아닌 새 화면 안내용으로 전환 |
| 현재 화면 상태 | 밝은 화면·어두운 화면·정보 밀도에 따라 실제 결과 표시 |
| 핵심 내용 | 배경, 글자, 강조색, 상태 표현, 글자와 간격 기준을 먼저 표시 |
| 상세 수치 | 별도의 상세 목록으로 분리 |
| 화면 크기 기준 | 전체 공통 기준, 특정 기능 기준, 공통 패턴 기준으로 분리 |

### 5.3 실제 사용 화면에 가까운 검토 추가

단순히 색상 이름만 나열하지 않고, 성공·주의·오류 상태에서 배경, 테두리, 글자가 함께 어떻게 보이는지 확인할 수 있게 했다.

이제 색 하나가 아니라 실제 안내 상자나 상태 표시 전체가 읽기 쉬운지 판단할 수 있다.

## 6. 기본 화면 구성 요소 안내 정리

화면을 만들 때 반복적으로 사용하는 기본 요소의 안내 화면을 역할별로 정리했다.

| 종류 | 개선 내용 |
|---|---|
| 세로 배치 | 위에서 아래로 내용을 쌓는 상황을 분리해 안내 |
| 가로 배치 | 좁은 화면에서 자연스럽게 다음 줄로 넘어가는 상태 추가 |
| 여러 칸 배치 | 화면 폭에 따라 칸 수가 달라지는 모습을 안내 |
| 화면 폭 제한 | 내용이 너무 넓어지지 않도록 하는 영역의 역할 안내 |
| 배경과 카드 | 서로 다른 높이감과 용도의 차이 안내 |
| 글자 | 제목·본문·보조 정보의 역할과 실제 문구 예시 추가 |
| 이미지 위 표시 | 선택 박스, 점, 조절점, 이름표의 다양한 상태 추가 |

### 6.1 글자 안내 개선

글자 크기를 설명할 때 짧은 영어 예시만 쓰지 않고, 한국어·영어·숫자가 섞인 실제 제품 문구를 사용했다.

이제 긴 제목, 시간, 이미지 수, 보조 설명 같은 실제 상황에서 줄바꿈과 읽기 쉬운 정도를 판단할 수 있다.

### 6.2 작은 화면 확인

작은 화면에서 가로로 나열되는 항목이 잘리는 대신 다음 줄로 자연스럽게 넘어가는지 확인하는 화면을 추가했다.

이는 좁은 화면에서 생길 수 있는 가로 잘림 문제를 미리 발견하기 위한 조치다.

### 6.3 이미지 위 표시 요소 색상 정리

이미지 위에 나타나는 선택 박스와 점 표시가 밝은 화면과 어두운 화면에서 모두 자연스럽게 보이도록, 화면 상태에 맞는 색을 사용하도록 정리했다.

## 7. 키보드 접근성 보완

### 7.1 발견한 문제

자동 접근성 검사에서 스크롤할 수 있는 영역이 키보드만으로는 선택하기 어려운 문제가 발견되었다.

### 7.2 처리 결과

스크롤 영역을 키보드로 선택할 수 있게 보완했다.

| 대상 | 이전 상태 | 개선 후 |
|---|---|---|
| 스크롤 가능한 내용 영역 | 마우스 없이 이동하기 어려움 | 키보드로 선택 후 내용 확인 가능 |

이 변화는 눈에 바로 보이는 디자인 변화는 작지만, 마우스를 사용하기 어려운 사용자에게 중요한 개선이다.

## 9. 반영과 미리보기 갱신

오늘 작업은 두 묶음으로 기본 작업 공간에 반영했다.

| 순서 | 반영 내용 |
|---|---|
| 첫 번째 | 데이터 선택·연결·촬영 화면의 공통 배치와 글자 표현 정리 |
| 두 번째 | 토큰 안내 화면과 기본 구성 요소 안내 재구성, 키보드 접근성 보완 |

또한 기본 미리보기 화면을 최신 상태로 다시 시작했다. 따라서 현재 기본 미리보기에서 오늘 반영한 내용을 확인할 수 있다.

오래된 백업, 시험용 작업, 별도 기능 작업은 현재 작업과 직접 연결되지 않았고 안전하게 검토되지 않았기 때문에 자동으로 합치지 않았다.

## 10. 남은 작업과 권장 우선순위

1. **토큰 안내 화면 디자인 검토**
   - 카드 간격, 정보량, 색상 표현이 실제 사용 목적에 맞는지 확인한다.
   - 특히 밝은 화면과 어두운 화면을 각각 보고 판단한다.

2. **토큰 찾기 기능 추가**
   - 필요한 색상, 글자, 간격 기준을 더 빠르게 찾을 수 있도록 검색과 분류 이동 기능을 추가한다.

3. **복사 기능 추가**
   - 토큰 이름이나 값을 쉽게 복사할 수 있도록 보완한다.

4. **기본 화면 구성 요소 예시 확장**
   - 더 많은 작은 화면, 긴 문구, 비어 있는 상태를 추가해 실제 화면과 가까운 검토를 이어 간다.

5. **완료된 작업 공간 정리 여부 결정**
   - 이미 기본 작업 공간에 반영된 작업 공간과 가지를 보관할지 정리할지 결정한다.

## 11. 결론

오늘 작업으로 화면을 만드는 기준과 그것을 확인하는 방식이 더 명확해졌다.

데이터 선택, 연결, 촬영 화면은 반복되는 배치와 글자 표현을 같은 기준으로 사용하게 되었고, 기능별로 꼭 필요한 고유한 모습은 유지했다. 토큰 안내 화면은 핵심 정보와 상세 정보를 분리해 더 이해하기 쉬워졌으며, 밝은 화면과 어두운 화면에서 실제 결과를 확인할 수 있게 되었다.

기본 화면 구성 요소의 안내도 역할별로 정리되어, 앞으로 새 화면을 만들거나 수정할 때 같은 문제를 반복해서 판단해야 하는 부담이 줄어들 것으로 기대한다.
