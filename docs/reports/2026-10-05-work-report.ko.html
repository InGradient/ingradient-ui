11. CI 복구와 작업 환경

  • 원인: unit 테스트가 @ingradient/edge-pages를 빌드 산출물(lib/)로 찾았다. CI는 빌드 전에 테스트를 돌려서 lib/가 없어 9월 21일부터 매번 실패했다. 로컬에서는 오래된 lib/가 남아 있어 실패가 가려져 있었다.
  • 수정: 테스트 설정이 TypeScript·Storybook과 같은 소스 경로를 쓰도록 맞추고, CI와 같은 Node 20을 .nvmrc로 고정했다.
  • 작업 환경: 모든 작업은 Omarchy(Linux)에서 진행한다. Node 20, Playwright, GitHub(simonkang76) 인증을 갖췄고 Mac은 확인용이다.
  • 시각 비교 기준: Omarchy와 CI(Ubuntu)는 한글·고정폭 글꼴 렌더링이 달라서, 기준 사진은 CI 캡처로만 갱신한다. 로컬 사진으로 갱신하지 않는다.
